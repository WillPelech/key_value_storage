Overview of TCP and UTP:

TCP:
Three way handshake:
    SYN - Client to server
    SYN-ACK - Server to client
    ACK - Client to server
DATA TRANSFER:
    DATA - Client to server
    DATA - Server to client
Four way handshake:
    FIN - Client to server
    FIN-ACK - Server to client
    ACK - Client to server
    FIN - Server to client

What is creating a server socket:
 Creating a server socket is the process of setting up a socket that is bound to a specific port and address
 , and is listening for incoming connections from clients.
